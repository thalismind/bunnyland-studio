# Studio operations

## Real-map services

Real-map setup accepts configurable service endpoints and requires an identifiable contact
string:

```json
{
  "nominatim_url": "https://nominatim.openstreetmap.org",
  "osrm_url": "https://router.project-osrm.org",
  "overpass_url": "https://overpass-api.de/api/interpreter",
  "tile_url": "https://tile.openstreetmap.org/{z}/{x}/{y}.png",
  "contact": "operator@example.invalid"
}
```

Requests happen during generation only. The client uses bounded results, a twelve-second
timeout, an identifying user agent, and in-process search/route caches. Operators using public
Nominatim must follow its usage policy; production or frequent workloads should configure
self-hosted endpoints. Do not fabricate a real fuel station when OSM data has a gap.

References:

- [Nominatim search API](https://nominatim.org/release-docs/latest/api/Search/)
- [Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/)
- [OSRM route API](https://project-osrm.org/docs/)
- [OpenStreetMap attribution guidelines](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)

## Attribution

The real-map generator persists stable OSM identity, coordinates, and `© OpenStreetMap
contributors (ODbL)` attribution. The web map displays that attribution below the map and also
passes it to Leaflet’s tile layer. Preserve visible attribution when replacing the tile source,
and add any additional attribution required by that provider.

Fictional maps are labelled “Fictional geography generated by Bunnyland Studio” and do not
claim an OSM origin.

## Deployment

Build the server wheel and install it into the same environment as Bunnyland Server. The
`bunnyland.plugins` entry point discovers `bunnyland.studio`; no source-path import flag is
needed. Build `web/` and copy its `dist/` contents to the host web image’s `/studio/` directory.

The reverse proxy must forward `/api/` HTTP and WebSocket requests to Bunnyland Server while
serving `/studio/` with SPA fallback to `/studio/index.html`. Keep the server and browser on the
same site so secure authentication cookies retain their normal scope and CSRF/origin policy.
